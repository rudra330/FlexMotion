# **App Name**: FlexMotion Recorder

## Core Features:

- Dummy Sensor Data Generation: Generate dummy flex sensor data for six sensors (5 fingers and wrist).
- Real-Time Data Recording: Record the dummy sensor data in real-time, simulating live sensor input.
- Data Visualization: Display six real-time graphs, one for each flex sensor, showing the recorded data.
- 3D Hand Model: Display and animate a 3D hand model (left and right), driven by the sensor data to visualize finger and wrist movement.
- Data Export: Export the recorded sensor data to a CSV file format.
- File Download: Enable users to download the generated CSV file.

## Style Guidelines:

- Primary color: Sky blue (#87CEEB), evoking a sense of technology, openness and calm.
- Background color: Light gray (#F0F0F0), providing a clean and neutral backdrop.
- Accent color: Electric purple (#BF5FFF), used sparingly to draw attention to interactive elements and key data points.
- Body and headline font: 'Inter', a grotesque-style sans-serif offering a modern and neutral feel.
- Use clear, simple icons to represent different functions, ensuring ease of use.
- Employ a clean, intuitive layout that provides an effortless user experience
- Utilize subtle animations on the graphs to make them appear dynamically without diverting attention.
